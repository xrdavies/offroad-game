## 安装包

本轮产物：`build/OffRoadRider-0.3.0.dmg`。编码器由 `native/recorder.swift` 和 `tools/build_recorder.sh` 构建，包含 arm64 / x86_64 两种架构；导出插件将 helper 装入 PCK。包内资源的录制回归与签名/校验结果在下方最终记录中。

macOS 导出模板不支持开发版的 `--script` 测试入口，因此包内代码的自动录制检查使用本机同版本 Godot 加载 DMG 内的 PCK，并在源项目目录之外运行。独立 App 已启动，但锁屏期间没有完成玩家手动按键流程的验收；不能把 PCK 测试描述为对最终 App 菜单的完整人工检查。

## 尚未验收或未实现

- 模型、植被、场景构图与音频尚未经过发布级美术、听音和混音验收。
- 当前仍是带辅助稳定的射线悬挂驾驶模型；没有完整机械传动、轮胎变形、可变形泥地、损伤或绞盘。
- 没有自动保存过去若干秒的精彩回放；当前支持主动开始/停止录像与独立镜头拍摄。
- 录制暂限 macOS；未实测 Intel Mac、Windows/Linux 录制、长时间录制、磁盘写满和异常断电后的文件恢复。
- 未验证全地图每一条越野路线；地点发现仍只保留到本次运行结束，未完成存档和手柄支持。
- 未完成 Apple Developer ID 签名、公证及首次下载后的 Gatekeeper 流程。当前包仅有临时签名。
- 新镜头启用了物理插值；本轮没有重新完成显示器端高速残影的专项调查，不能据此宣布先前残影问题已解决。
