# 验证记录与发布差距

当前目标平台是工作机上的 macOS / Apple M4 / 16 GB / Godot 4.7.2。当前状态：可玩的开发构建，未完成商业发布验收。

| 项目 | 状态与证据 |
| --- | --- |
| 标准资源导入 | 已通过；模型、声音、着色器和 JSON 均在项目内 |
| 驾驶行为 | `tests/smoke.gd`：四轮接地、静止、加速、右转、手刹、重置、空中动力限制、浅水和暂停 |
| 地图通行 | `tests/smoke.gd`：两座桥分别从河岸驶到对岸；尚未逐米检查所有越野路线 |
| 实际渲染 | 已检查修理站、废车场、河道、桥梁、采石区和地图；截图见 `docs/previews/` |
| 性能 | 本机 1280×720 多个短时静止截图场景，Metal / Forward+ 输出约 54–114 FPS，约 175–311 次绘制调用；受同时运行的测试影响，不是长时间性能保证 |
| 资源包 | `build/Dustline.pck` 已在项目目录外加载运行；不依赖源目录中的原始 PCM |
| 音频 | 循环衔接与峰值的程序校验已通过；未完成专业听音、参考配乐对照和最终混音 |
| 美术达到参考视频品质 | 未通过最终验收；模型破损细节、植被、场景密度与调色仍需进一步打磨 |
| 原地图完整复刻 | 无法从这段剪辑确定全地图；本版是可见元素的连通重建 |
| 塔防、升级、配乐 | 等待用户确认是否包含；未将未实现功能描述为已完成 |
| 存档、手柄、多分辨率与长时间测试 | 未完成；地点发现只保留到本次运行结束 |
| 独立 macOS 安装包 | 未导出；本机未安装对应导出模板，尚未签名或公证 |
| Git 远程备份 | 本地提交；未配置远程地址 |

`--quit-after` 强制退出的无界面进程可能输出 Godot 的 AudioStreamPlaybackWAV 退出时资源释放警告。行为测试在释放场景后等待音频线程，正常退出菜单也会先停止声音。该警告不等同于音频加载失败，但仍应在发布前的长时运行/退出测试中跟踪。
