# 地图场景打磨计划

本文规划现有三张地图的场景、路线和驾驶体验打磨，不新增第四张地图。当前地图由 `maps.gd`、`regions.gd`、`world.gd` 生成，尺寸为 1,440 × 1,200 米，三张地图独立切换。目标是先把现有地图做出清晰的主题、路线和可记忆地标，再增加任务和玩法。

## 当前基线

现有地图组合如下：

| 地图 | 当前主题 | 当前主要区域 |
| --- | --- | --- |
| **Old Frontier** | 废土综合探险 | 修理站、废车场、森林、草原、山地、沙漠、泥地、沼泽、戈壁、废墟、Granite Gate 攀岩区、芦苇湖 |
| **Salt Coast** | 海岸与港口废墟 | 海滩、静默港、沙丘、红石平地、潮汐沼泽、海岸草地、绿洲湖 |
| **Alpine Reach** | 雪山和高山路线 | 松林山谷、高山草甸、Eagle Pass、White Crown 雪山、Broken Ridge 攀岩区、冰湖、高山湖泊 |

当前地图是原创扩展，不是参考视频的逐坐标复刻。地形和可见装饰已经存在，但路线、材质边界、地标密度、障碍物层次和全地图长期驾驶仍需要继续打磨。

## 统一地图打磨标准

1. **主题一眼可见**：进入地图 10 秒内能看出它与另外两张地图的差别。
2. **路线有选择**：每张地图至少有安全路线、技术路线和探索路线，不把所有地形只放在一条环路上。
3. **地标可记忆**：每个区域有独特形状、颜色、设施或声音，玩家能凭环境判断位置。
4. **地形影响驾驶**：泥、沙、冰、浅水、岩石和雪要有明确抓地、阻力、悬挂或视听反馈。
5. **障碍有层次**：小障碍用于节奏，中型障碍用于选线，大型障碍用于形成地图挑战点。
6. **道路和碰撞一致**：看得到的桥、石块、树干、废墟和台阶都应有合理碰撞；路线不能穿过不可见墙体。
7. **视觉密度稳定**：主路线有引导，远景有地标，非路线区域不应突然变成空白平面。
8. **性能可控**：保持区块化生成和 MultiMesh 合批，先完成采样性能再继续增加植被和装饰数量。

## Old Frontier：废土综合探险

### 需要突出的特征

- 修理站、油泵、废车场是玩家的主要方向参照。
- 泥地、沼泽、森林、草原和戈壁之间形成明显的颜色与植被过渡。
- Granite Gate 是核心岩石攀爬地标，应从远处就能看到岩门、旗杆和阶梯轮廓。
- 芦苇湖和废墟街区承担“绕路探索”功能，而不是只作为背景。

### 建议路线结构

1. **服务站环线**：修理站 → 废车场 → 双桥 → 修理站，适合新玩家和高速车辆。
2. **技术攀岩线**：森林边缘 → 泥地 → Granite Gate 中央阶梯/侧坡 → 戈壁平台，适合 Wrangler、Unimog 和六轮车。
3. **探索支线**：废墟街区 → 芦苇湖 → 沼泽木栈道 → 草原设施，放置隐藏地点和摄影位置。

### 场景补强重点

- 让废车场形成可穿行的窄巷、堆叠坡和可见出口，避免只是一片装饰堆。
- 将 Granite Gate 的中央阶梯、错位巨石、侧坡和护栏做成连续驾驶段，增加不同高度的落脚点。
- 为泥地和沼泽增加车辙、积水、低矮灌木和被压倒的草。
- 为废墟增加残墙、倾斜电线杆、破损路牌和室内可穿行空间。

## Salt Coast：海岸与港口废墟

### 需要突出的特征

- 海岸线、港口设施和潮汐湿地是核心识别点。
- 沙地应强调漂移、沉陷和扬沙；湿地应强调低速、积水和视线遮挡。
- 红石平地和沙丘需要形成高度变化，避免整张地图变成同色平面。

### 建议路线结构

1. **海岸观景线**：出生点 → 沙滩 → 海岸悬崖/观景地标 → 返程，适合拍摄和高速巡游。
2. **港口技术线**：静默港 → 集装箱窄道 → 河口浅水 → 潮汐沼泽，适合窄车和低速车。
3. **沙漠远征线**：沙丘 → 红石平地 → 绿洲湖 → 港口，适合 F-150、Hilux 和长距离车辆。

### 场景补强重点

- 海滩与深水边界要有泡沫、湿沙和可见的水位变化，不能只靠一张水面。
- 港口增加可穿行集装箱区、吊机骨架、锈蚀管线和斜坡码头。
- 潮汐沼泽增加芦苇、木桩、浅水坑和被水冲刷的路径边缘。
- 沙丘增加明显风蚀纹理、轮胎陷入反馈和远处海岸/港口地标。

## Alpine Reach：雪山和高山路线

### 需要突出的特征

- 远景雪山和松林山谷负责建立尺度；Eagle Pass 和 Broken Ridge 负责驾驶挑战。
- 雪、岩石、草甸和冰面要同时有视觉和物理差异。
- 冰湖应该是可识别的路线节点，而不是单一蓝色平面。

### 建议路线结构

1. **山谷环线**：松林 → 高山草甸 → 高山湖泊 → 松林，适合 Scout、Hilux 等综合车辆。
2. **山口技术线**：Broken Ridge → Eagle Pass → White Crown 低坡，适合 Wrangler、Unimog 和六轮车。
3. **冰湖探索线**：冰湖入口 → 裂纹冰面 → 湖边营地 → 雪坡返程，适合测试低抓地力和制动。

### 场景补强重点

- 雪地加入轮胎压痕、积雪边缘、风吹雪纹和松树挂雪。
- 山口增加明确的落石区、护栏、窄桥和可绕行路线。
- 冰湖增加裂纹、薄冰警示、岸边雪堆和反射变化；碰撞边界必须和可见冰面一致。
- 高山远景使用分层山体、雾气和冷色光照，避免只靠地面颜色表达雪山。

## 三张地图共同的 P0/P1/P2

### P0：路线和驾驶可读性

- 每张地图先完成 3 条可从起点走通的路线：安全、技术、探索。
- 为每条路线设置起点、终点、路线标识和一个可记忆的中间地标。
- 修正地形表面与实际碰撞不一致的地方，特别是桥、台阶、浅水、冰面和废墟。
- 对每张地图各跑一次完整路线，记录卡住点、无意义绕路、空白区域和镜头遮挡。

### P1：场景密度和地形表达

- 给主路线增加近景障碍、边缘植被、路牌和远景参照物。
- 做好泥/沙/雪/冰/水的材质过渡、车辙、尘土、水花和声音变化。
- 将每个区域的设施、植被和岩石形状做出组合规则，减少随机堆放感。
- 每张地图保留至少一个适合第一人称驾驶、一个适合第三人称驾驶、一个适合录像的观景点。

### P2：地图系统和长期体验

- 将发现地点、路线完成和地图探索记录纳入存档。
- 增加天气/时间变化前，先完成固定光照下的场景构图和性能基线。
- 地图之间暂不做无缝连接；先把切换界面、加载等待和车辆/视角保留做稳定。
- 以后若增加任务，直接复用这些路线、地标和地形标签，不再另造一套任务专用地图。

## 地图验收标准

每张地图完成一轮打磨后，需要提交：

- 地图总览图、三条路线图、每个核心区域的近景图。
- 三条路线各一段实际驾驶记录，包含至少两种地形转换。
- 第一人称和第三人称各一次完整路线检查。
- 桥、岩石、树干、废墟、浅水、冰面和山坡碰撞检查。
- 每类地形的抓地、阻力、音效、尘土/水花和轮迹检查。
- 主机目标分辨率下的短时帧率和长路线稳定性记录。

地图完成标准不是“地形种类更多”，而是玩家能记住路线、辨认区域、感受到地形差异，并愿意用不同车辆再次走同一张地图。
