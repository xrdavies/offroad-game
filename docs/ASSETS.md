# 素材清单与来源

本版的模型、几何体、着色器、音效和地图数据均在项目内原创编写，没有从参考视频提取贴图、模型或音乐。参考视频只用于观察视觉风格、物体类型和玩法。UI 使用 Godot 自带字体。

## 模型

所有模型位于 `assets/models/`，源文件为 `tools/build_assets.gd`。模型将主要彩色几何体合并到一个网格；新车辆的外部车窗单独放在第 2 渲染层，驾驶舱视角隐藏该层，便于复用并控制绘制调用；需要阻挡车辆的场景包含静态碰撞形状。

| 资源 | 用途 |
| --- | --- |
| `scout_body.tscn` | 越野车，车窗、行李架、货箱、保险杠、灯、备胎、涉水管 |
| `scout_wheel.tscn` | 带胎纹、轮毂的独立轮胎，悬挂与转向驱动 |
| `wreck_0` 至 `wreck_5.tscn` | 轿车、旅行车、皮卡、厢式车、掀盖破车与烧毁车壳；空车窗、座椅、发动机、轮拱和成片锈蚀 |
| `salvage_0` 至 `salvage_3.tscn` | 中空废轮胎、废旧洗衣机、波纹金属板、裸车架；组成垃圾山与场景小物 |
| `garage.tscn` | 可驶入的修理站、雨棚、门窗、波纹屋顶 |
| `fuel_pump.tscn` | 油泵与油管 |
| `container.tscn` | 带波纹与门杆的集装箱 |
| `palm.tscn` | 分段树干、弯曲叶轴和成对下垂叶片 |
| `utility_pole.tscn` | 电线杆与绝缘子，线路由地图连接 |
| `barrel.tscn` | 锈蚀色金属桶 |
| `barrier.tscn` | 混凝土路障 |
| `fence.tscn` | 带斜交菱形网的围栏模块 |
| `water_tank.tscn` | 高架水塔 |
| `relay.tscn` | 中继设施与天线 |

共 31 个独立模型场景。`world.gd` 还生成不规则层状岩壁、桥梁、地形、路面、成片荒草、碎石、废料山与标牌。垃圾山直接使用可见地形的碰撞面，细小废料作为装饰；草、碎石和废料按 32 米区域使用 MultiMesh 合批，屏幕外区域可被剔除。水面、道路、岩壁和地面材质分别位于 `assets/water.gdshader`、`assets/road.gdshader`、`assets/rock.gdshader`、`assets/ground.gdshader`。浅滩泡沫由水面与河床的深度差控制，道路增加磨损边线与裂纹。这些是原生几何体和着色器资产，不是位图占位图。

## 音效

| 文件（`assets/audio/`） | 长度 | 行为 |
| --- | --- | --- |
| `engine.wav` | 3 秒 | 随油门和速度调整音高、音量 |
| `gravel.wav` | 4 秒 | 砂石地面行驶时混入 |
| `water.wav` | 4 秒 | 浅水行驶时混入 |
| `wind.wav` | 8 秒 | 低音量环境风声 |
| `impact.wav` | 0.48 秒 | 有实际碰撞和速度突变时触发 |
| `discovery.wav` | 1 秒 | 第一次发现地点时触发 |

均为 44.1 kHz / 16-bit / 单声道 WAV；使用项目内确定性合成程序生成，循环带交叉衔接、去直流偏移与峰值校验。Godot 通过标准导入资源加载。这里没有完整配乐，也没有声称已完成专业听音和混音验收。

`.uid` 与 `.import` 是需要提交的资源标识和导入设置；`.godot/` 是可重建的导入缓存。所有当前游戏引用的资源都在仓库内，构建不依赖 `/tmp` 或在线生成服务。

## 0.3.0 追加资产

`ridge_body.tscn`、`pickup_body.tscn`、`hauler_body.tscn` 与重建的 `scout_body.tscn` 共享 `vehicles.gd` 尺寸数据和 `tools/build_assets.gd` 生成器。包含驾驶舱、仪表、座椅、车身、外部车窗、货斗或行李架；动态方向盘由 `car.gd` 创建。全部为虚构车型，不使用真实车标。

`regions.gd` 生成分层体素树冠、树林与湿地植被、碰撞树干和岩块、木材堆、太阳能补给站、栈道、越野小径和区域路牌；既有场景模型复用为林区营地、草原农场和山地设施。原视频提供色调、体素形状、废土设施与湿地参考，新地理布局与其他生物群系是本项目设计，没有取用原作模型。

## 驾驶舱近景细化

四款车共享按座位高度适配的精细内饰：平滑法线的圆角仪表台和门板、64 段方向盘及包边、金属轮辐、带刻度和数字的仪表、出风口叶片、旋钮与开关、手套箱、扶手、带缝线和侧翼的座椅、换挡杆防尘套、脚垫和踏板。高座舱车型也有完整的前围与地板，不再透视到车外。

方向盘模型现在随车身场景烘焙，`car.gd` 驱动它的转向；速度指针、数字读数和方位指针实时变化。仪表数字使用 Godot 内置字体。后视镜、收音机、开关、踏板和换挡杆目前是外观细节，没有新增实时镜面影像、收音机或独立机械操作功能。

源文件仍为 `tools/build_assets.gd`；使用 `-- --vehicles-only` 可只重建十款车，避免改写场景装饰资源。模型场景总数为 31，没有新增外部贴图、字体或依赖。

## 十车型与三地图追加资产

新增 `wrangler_body.tscn`、`unimog_body.tscn`、`f150_body.tscn`、`hilux_body.tscn`、`eq246_body.tscn`、`wc62_body.tscn`。原有四款车保留 ID 并重建外观。十车共用重新细化的 32 段胎体、轮毂螺栓和双排胎纹，按照各自轮径缩放；车身分别生成，六轮车型有三根车轴。所有车保留动态仪表、方向盘和可用的第一人称驾驶位。

`maps.gd` 定义地图尺寸、配色、起点和固定随机种子；`regions.gd` 新增不规则岩块、攀爬台阶、楼房骨架与坍塌墙面、搁浅船体、松树、湖泊码头和冰面裂纹。`world.gd` 构建河床、湖盆、海岸和区块化地形。全部由项目代码生成，未增加外部美术依赖。实车资料仅用于轮廓与特征参考，来源和设计差异见 [车队与地图设计](FLEET_AND_MAPS.md)。
